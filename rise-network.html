Introduction

Why this lesson matters

When the network is healthy nobody notices it. When it fails, the whole office stops: no email, no shared files, no printing. Administrators are the people who keep it quiet.

In about 20 minutes you will learn how the parts fit together and a repeatable way to find faults.

By the end you will be able to
  • Name the job of a switch, router, firewall, DHCP and DNS
  • Trace how a request travels from a laptop to the internet
  • Troubleshoot a fault from the bottom layer up
  • Apply four routine habits that prevent most outages
Section 1

How the network works

Before you can fix a network you need a clear picture of what each device does and what happens when someone opens a web page.

Key ideaEvery network problem is a break somewhere along a path. Know the path and you know where to look.

The core components

Connects the devices inside the office. It learns which device sits on which port and sends each frame only where it needs to go. It works with MAC addresses and does not leave the local network.

Connects the office network to other networks, including the internet. It reads the destination IP address and chooses the next hop. Your devices use it as their default gateway.

Allows or blocks traffic by rule: which address, which port, which direction. The safe default is to block everything inbound and allow only what the business needs.

Hands out an IP address, subnet mask, gateway and DNS server to each device that joins, so nobody types them by hand. Printers and servers usually get fixed (static) addresses instead.

Turns names such as intranet.example.com into IP addresses. Think of it as the phone book. If it fails, the internet seems down even though the connection is fine.

The office at a glance

What happens when you open a web page

  1. Ask DNS for the address

    The laptop asks the DNS server to turn the site name into an IP address.

  2. Send to the gateway

    The destination is outside the office, so the laptop sends the data to its default gateway through the switch.

  3. Router forwards it

    The firewall checks the rules, then the router sends the traffic on towards the internet.

  4. Reply comes back

    The web server answers, and the reply follows the path in reverse until it reaches the laptop.

Section 2

Fix, secure and maintain

A calm, repeatable method beats guessing. Then four habits keep faults from coming back.

Four faults you will see every week

Select a card to see the likely cause and first fix.

A method for finding the fault

  1. Define the problem

    Who is affected, since when, and what changed? One user or everyone?

  2. Start at the bottom

    Check the physical layer first: cable, link lights, power.

  3. Move up one step at a time

    Address and gateway, then name resolution, then the application.

  4. Fix and test

    Change one thing at a time and confirm it worked.

  5. Record it

    Write down the cause and fix so the next person finds it in seconds.

Four habits that prevent outages

Control who can do what

Give each person only the access their job needs, and remove it the day they leave.

Least privilegeUnique accountsMulti-factor sign-in

Keep firmware and software current

Most attacks use flaws that already have a fix. Schedule updates, test them on one device first, and keep a list of what runs where.

Monthly windowTest firstAsset list

Back up, then prove you can restore

A backup nobody has restored is only a hope. Keep a copy off site and test a restore every quarter. Back up device configurations too.

See problems before users do

Watch link usage, device temperature, disk space and failed sign-ins. Set alerts for the few numbers that matter, not for everything.

Summary

What to take with you

Know the path

Device, switch, gateway, router, internet. Each part has one clear job.

Work bottom-up

Cable first, then address, then names, then the application. Change one thing at a time.

Prevent, don't just fix

Limit access, patch, back up and test the restore, and watch the numbers that matter.
